# Supervised learning, k-NN and decision trees

## Machine learning
Machine learning learns patterns from data instead of using hand-crafted rules. Supervised learning uses labelled examples. Unsupervised learning finds structure in unlabelled data. Reinforcement learning uses rewards from trial and error. Use machine learning for complex patterns, many edge cases and changing data. Use rules when the logic is exact, the data is tiny, errors are unacceptable or the reasons must be clear.

## Supervised learning
The model learns from features and labels to predict unseen cases. Classification predicts a category and regression predicts a continuous number. A classifier outputs a probability for each class, and a threshold turns the probabilities into labels. The threshold balances the cost of false positives against the cost of false negatives.

## Evaluating classifiers
The confusion matrix holds the counts of true and false positives and negatives. Accuracy is misleading when classes are imbalanced. Precision matters when false positives are costly. Recall matters when missing a positive is costly. F1 balances precision and recall. Specificity measures how well negatives are rejected. The ROC curve plots the true positive rate against the false positive rate across thresholds.

## k-nearest neighbours
k-NN finds the k closest training points and takes a majority vote for classification. For regression it averages their values. It is lazy because it does little work in training. It is non-parametric because it assumes no data distribution. Choose k by comparing values on validation data. Its drawbacks are high cost on large data, sensitivity to irrelevant features and dependence on the choice of k.

## Decision trees
A tree makes a series of splits that give readable if then rules. Gini impurity shows how mixed a node is, and zero means the node is pure. The tree picks the split with the largest drop in weighted impurity, then repeats on each child. It stops when nodes are pure, features run out, or a limit such as maximum depth is reached. An impure leaf predicts its majority class.

## k-NN compared with decision trees
| Point | k-NN | Decision tree |
|---|---|---|
| Training work | Almost none | Builds the splits |
| Prediction | Majority vote or average of the k nearest neighbours | Follows readable rules to a leaf |
| Main weakness | Slow and memory-heavy on large data | Leaves can stay impure |
