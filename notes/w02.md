# Supervised learning, k-NN and decision trees

## Machine learning
**What it is.** Machine learning is a branch of AI where computer systems learn patterns from data, usually historical data, to improve at a task. They do not rely on hand-crafted rules.

**Three paradigms.** Supervised learning uses labelled examples, so each example comes with the right answer. Unsupervised learning finds structure in unlabelled data, with no answers given. Reinforcement learning learns by trial and error, guided by rewards and penalties, as when an agent learns a game by trying moves.

**Why use it instead of rules.** Rules struggle when patterns are complex, such as spam, fraud or images, because nobody can write them all down. They fail when there are many edge cases, because the rule list explodes. They fail when data changes, because behaviour drifts over time, called concept drift, and a model can simply be retrained.

**When not to use it.** Choose rules or verified algorithms when data is tiny or poor, because the model will overfit and a simple rule does better. Choose them when logic is deterministic, such as tax bands. Choose them when errors are unacceptable, such as dose calculation or flight control. Choose them when clear, auditable reasons are required.

## Supervised learning
**What it is.** A model learns from labelled historical data to predict unseen cases. Each example has input features, also called independent variables or predictors, and an output label, also called the dependent variable or target.

**Classification and regression.** Classification predicts a discrete category, such as default or no default, or one of several classes. Regression predicts a continuous number, such as price or journey time. The test is the type of answer. A category is classification. A number on a scale is regression.

**Example.** Deciding from a chest X-ray whether a patient has pneumonia is classification. Forecasting travel time in minutes is regression.

**Easily confused.** A count of tickets is a number, so it is regression. Having several classes does not turn classification into regression.

## How a classifier makes a decision
The model learns patterns that separate the categories and outputs a probability for each class. A threshold then turns the probabilities into a final label. The threshold is chosen after the model has produced its probabilities, and it balances real-world costs. Raising it gives fewer false alarms but more missed cases, and lowering it does the opposite.

## Evaluating classifiers
**Confusion matrix.** It counts true positives, false positives, true negatives and false negatives. Every other measure comes from these four counts.

**Accuracy.** The share of all predictions that are correct. It misleads on imbalanced data. If almost every case is in one class, a model that always predicts that class scores high accuracy while catching nothing useful.

**Precision and recall.** Precision asks of the items predicted positive, how many really are positive. It matters when false positives are costly, such as a fraud team with few investigators. Recall, also called sensitivity, asks of all the real positives, how many were caught. It matters when a miss is costly, such as disease screening. The two pull against each other, since catching more positives usually brings more false alarms.

**Easily confused.** Precision looks at the predictions and recall looks at the real cases. Specificity looks at the real negatives and asks how many were correctly rejected.

**F1 and ROC.** F1 is the harmonic mean of precision and recall, giving one balanced number when classes are imbalanced. The ROC curve plots the true positive rate against the false positive rate across thresholds, with each point being one threshold. The area under it, AUC, summarises how well the model ranks positives above negatives.

## k-nearest neighbours
**What it is.** k-NN is a simple, non-parametric, lazy algorithm for classification and regression. It finds the k training points closest to the new point and predicts from them.

**How it works.** First choose k. Then measure the distance from the new point to the training points, for example with Euclidean distance, and find the k nearest. Finally, for classification take a majority vote among them, and for regression average their values.

**Example.** For a new medical case plotted by age and number of nodes, one neighbour may say survived while a larger k changes the vote. The class can change with k because different neighbours are counted.

**Lazy and non-parametric.** Lazy means it does very little at training time and does the work when asked to predict. Non-parametric means it assumes no particular data distribution.

**Choosing k.** Start from an estimate based on the number of samples, then test values around it on validation data. Compare them with a performance metric and keep the best, using cross-validation for reliability. Judging on training data would favour k equal to one, which just memorises the training set.

**Strengths and drawbacks.** It is simple, has no training phase and handles both tasks. It costs a lot of memory and computation on large data, is hurt by irrelevant features and noise, and depends heavily on k. Unscaled features also hurt, since the feature with the largest range, such as income in pounds against age in years, dominates the distance.

## Decision trees
**What it is.** A decision tree makes a series of splits on features that produce readable if then rules, ending in leaves that give a prediction.

**Gini impurity.** It measures how mixed a node is, as the chance of mislabelling a random sample if you label it by the node's class mix. Zero means the node is pure, with all samples in one class.

**How a split is chosen.** At each node the tree tries each possible split and calculates the impurity of the child nodes, weighted by their size. It keeps the split with the biggest drop from the parent's impurity, called the gain. It repeats this on each child. In the weather example, splitting on Windy gave purer groups than splitting on Outlook, so Windy became the root. Textbooks also use entropy for this.

**When it stops.** It stops when nodes are pure, when no features remain, or when a limit such as maximum depth or minimum samples is reached.

**How it predicts.** A new case follows the rules from the root down to a leaf. A pure leaf predicts its single class. An impure leaf predicts its majority class, and the share of that class gives an estimated probability, such as two thirds.

**Easily confused with k-NN.** A tree does its work in training by building the splits, and prediction just follows rules. k-NN does almost nothing in training and does its work at prediction.
