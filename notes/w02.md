# Supervised learning, k-NN and decision trees

## Machine learning
Machine learning learns patterns from data instead of using hand-crafted rules. Supervised learning uses labelled examples. Unsupervised learning finds structure. Reinforcement learning uses rewards from trial and error. Use machine learning for complex patterns, many edge cases and changing data. Use rules when logic is exact, data is tiny, errors are unacceptable or reasons must be clear.

## Supervised learning
The model learns from features and labels to predict unseen cases. Classification predicts a category and regression predicts a continuous number. A classifier outputs probabilities and a threshold turns them into labels. The threshold balances the cost of false positives and false negatives.

## Evaluating classifiers
The confusion matrix holds true and false positives and negatives. Accuracy is misleading when classes are imbalanced. Precision matters when false positives are costly. Recall matters when missing a positive is costly. F1 balances the two. Specificity measures how well negatives are rejected. The ROC curve plots true positive rate against false positive rate across thresholds.

## k-nearest neighbours
k-NN finds the k closest training points and takes a majority vote for classification. For regression it averages their values. It is lazy because it does little work in training. It is non-parametric because it assumes no data distribution. Choose k by comparing values on validation data. Its drawbacks are high cost on large data, sensitivity to irrelevant features and dependence on k.

## Decision trees
A tree makes a series of splits that give readable if then rules. Gini impurity shows how mixed a node is, and zero means pure. The tree picks the split with the largest drop in weighted impurity. It then repeats on each child. It stops when nodes are pure, features run out, or limits such as depth are reached. An impure leaf predicts its majority class.

## Comparing the two
| Point | k-NN | Decision tree |
|---|---|---|
| Training | Almost none | Builds splits |
| Output | Vote of neighbours | Rules that can be read |
| Weak spot | Slow on large data | Impure leaves |
