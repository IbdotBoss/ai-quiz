# Unsupervised learning, clustering and principal component analysis

## Unsupervised learning

**What it is.** Unsupervised learning finds inherent structure or patterns in unlabelled data. There is no target column and no correct answer to copy. The two main types are clustering and dimensionality reduction.

**Compared with supervised learning.** Supervised learning uses labelled input and output pairs and aims to predict outcomes for new data. Linear regression, decision trees and neural networks are examples. Unsupervised learning uses unlabelled data and aims to describe the data itself. K-means, principal component analysis and autoencoders are examples.

**Example.** The Wine dataset holds chemical measurements of wines from one region of Italy, with no column naming the wine type. Market basket analysis, which finds products bought together, is another use.

## Clustering

**What it is.** Clustering groups similar data points together using their features, with no predefined labels. Points that are close under some measure, usually distance, go in the same cluster. It works as an exploratory tool for discovering hidden groupings.

**Example.** A shop groups customers by behaviour and preferences to tailor marketing.

**Methods.** K-means divides the data into k groups by minimising within-cluster variance. Hierarchical clustering builds a tree, called a dendrogram, showing how clusters merge or split. DBSCAN groups points by density and suits clusters of arbitrary shape. Gaussian mixture models are probabilistic and assume the data comes from Gaussian distributions.

## K-means

**What it is.** K-means is the most popular clustering algorithm. The user decides on k, the number of clusters, and the algorithm minimises the total squared distance between points and the centre of their cluster.

**How it works.** First it places k centres at random, because it has no better starting guess. Then it assigns every point to its closest centre, so each centre gets a group. Then it moves each centre to the mean position of its group, because the mean is the spot with the smallest squared distance to those points. Moving the centres changes which centre is closest for some points, so the assign and move steps repeat. The algorithm stops at convergence, when no point changes cluster.

**Example.** Plot customers by age and income and pick k as 2. Two random centres start on the plot, points join the nearer one, and the centres shift to the middle of their groups until nothing changes.

**Common mistakes.** Thinking k-means finds k for you, since the user must choose it. Expecting the same answer every run. Random starting centres mean two runs on the same data with the same k can give different clusters.

## K-means against DBSCAN

K-means works from centres and distances, needs k chosen in advance and tends to produce compact, roughly round groups. DBSCAN works from density, so it can follow clusters of arbitrary shape such as curved or irregular ones. Choose k-means for compact groups where a sensible k can be found, and choose DBSCAN when the clusters are irregular.

## Choosing k

**Inertia.** This is the sum of squared distances from each point to its cluster centre. Smaller means tighter clusters. It falls as k rises, because more centres sit closer to the points. So the lowest inertia is not the best choice, since using one cluster per point would give the lowest inertia and no useful grouping.

**Elbow method.** Plot inertia against k and look for the point where the improvement drops sharply. That bend is the elbow and marks a good k. The elbow can be hard to see.

**Silhouette score.** This measures how well each point fits its own cluster compared with other clusters. For one point, a is the average distance to the other points in its own cluster, which shows cohesion. The value b is the average distance to the points in the nearest neighbouring cluster, which shows separation. The score runs from minus 1 to plus 1. Near plus 1 means well clustered, near 0 means the point sits on a boundary, and negative means it may be misclassified. The overall score is the average across all points.

**Using the silhouette score to pick k.** Run k-means for several values of k, average the score for each, and plot k against the score. Choose the k with the highest score. A k that is too small gives broad clusters with low separation. A k that is too large splits the data into fragments and the score drops.

## Dimensionality reduction

**What it is.** Dimensionality reduction cuts the number of input features while keeping as much relevant information as possible. It projects the data into a lower-dimensional space.

**Why it is done.** Data with very many features is slow to process and hard to see, which is the curse of dimensionality. Fewer features make computation faster, remove noise and redundancy, reduce overfitting and allow plotting in two or three dimensions.

| Method | Main idea |
|---|---|
| Principal component analysis | Unsupervised, projects onto the directions of greatest variance |
| Linear discriminant analysis | Supervised, maximises separation between classes |
| t-SNE | Non-linear, preserves local structure for visualisation |
| UMAP | Non-linear, preserves local and global structure |

**Easily confused.** Principal component analysis and linear discriminant analysis both give linear projections. The difference is that linear discriminant analysis uses class labels and the other does not.

## Principal component analysis

**What it is.** Principal component analysis finds new directions, called principal components, along which the data varies most, and describes each row using only the first few.

**How it works.** First centre the data by subtracting each feature's mean, so every feature is measured from the same starting point. Next calculate the covariance matrix, which shows how each pair of features vary together. A positive value means they move in the same direction, a negative value means opposite directions and zero means no relation. Then use eigen-decomposition. An eigenvector is a direction that the matrix only stretches without turning. An eigenvalue is the stretch factor. Here the eigenvectors are the principal components and each eigenvalue shows how much variance lies along its direction. A large eigenvalue means that direction carries a lot of the variation. Finally project the data onto the top components.

**Example.** In a four-feature dataset, the first component holds about 96.6 percent of the variance and the first two hold about 99.2 percent. The features were highly redundant, and two components summarise them well.
