# Clustering and PCA

## Supervised and unsupervised learning
**Supervised learning** uses labelled input and output pairs and aims to predict outcomes for new data. **Unsupervised learning** uses unlabelled data and aims to find structure in the data itself. Its two main types are **clustering** and **dimensionality reduction**. A dataset of wine measurements with no column naming the wine type is an unsupervised problem.

## K-means
**K-means** groups unlabelled data into **K clusters**, with K chosen by the user. It places K **centroids** at random, assigns every point to its nearest centroid, then moves each centroid to the **mean** of its points. Moving the centroids changes which is nearest for some points, so the two steps repeat until no point changes cluster, called **convergence**. Its aim is to minimise **inertia**, the sum of squared distances from each point to its centroid.

> The random start means two runs with the same K can give different clusters.

## Choosing K and judging the clusters
The **elbow method** plots inertia against K. Inertia always falls as K grows, because more centroids sit closer to the points. The elbow is the K where the improvement suddenly drops, though it can be hard to see.

The **silhouette score** measures how well each point fits its cluster. For one point, a is the average distance to points in its own cluster, called cohesion, and b is the average distance to points in the nearest other cluster, called separation. The score runs from -1 to +1. Near +1 means the point fits its cluster well, near 0 means it sits between two clusters, and negative means it is probably in the wrong one. Run K-means for several values of K, average the score for each, and choose the K with the highest score.

> The lowest inertia is not the best K. One cluster per point gives zero inertia and no useful groups.

## Other clustering methods
**DBSCAN** groups points by density, so it can find clusters of any shape and does not need K in advance. **Hierarchical clustering** builds a tree diagram, called a dendrogram, showing how clusters merge or split.

## Principal component analysis
**Dimensionality reduction** cuts the number of features while keeping as much information as possible. It speeds up training, removes noise and redundancy, reduces overfitting and allows plots in two or three dimensions.

**Principal component analysis**, PCA, is unsupervised. It finds new directions, called **principal components**, along which the data varies most. The steps are as follows.

1. Centre the data by subtracting each feature's mean.
2. Calculate the **covariance matrix**, which shows how each pair of features varies together.
3. Find its **eigenvectors** and **eigenvalues**. Each eigenvector is a principal component, and its eigenvalue shows how much variance lies along it.
4. Project the data onto the top few components.

In the four-feature example, the first two components hold about 99% of the variance, so two numbers describe each row well.

> PCA uses no labels. Linear discriminant analysis uses class labels to separate the classes.
