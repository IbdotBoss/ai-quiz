# Unsupervised learning, clustering and principal component analysis

## Unsupervised learning
It uses unlabelled data and aims to find inherent structure or patterns. Supervised learning uses labelled data and aims to predict outcomes. Examples of unsupervised methods are k-means, principal component analysis and autoencoders. The two main types are clustering and dimensionality reduction.

## Clustering
Clustering groups similar data points together, with no labels or target. It is similarity based and works as an exploratory tool. Uses include customer segmentation and document clustering. Common methods are k-means, hierarchical clustering with a dendrogram, DBSCAN for density and arbitrary shapes, and Gaussian mixture models for probabilistic clusters.

## K-means
The user chooses k. The algorithm places k centres at random, assigns each point to its closest centre, moves each centre to the mean of its cluster, and repeats. It stops at convergence, when no point changes cluster. It minimises the total squared distance from points to their centres. Random starting centres mean results can differ between runs.

## Choosing k in k-means
- Inertia is the sum of squared distances from points to their cluster centre. Smaller means tighter clusters. It falls as k rises.
- The elbow method looks for the point where improvement drops sharply. It can be hard to see.
- The silhouette score compares cohesion with separation from the nearest other cluster. Values near 1 mean well clustered, near 0 mean on a boundary, and negative means possibly misclassified. Choose the k with the highest average score.

## Dimensionality reduction
It reduces the number of features while keeping relevant information. Benefits are speed, less noise and redundancy, less overfitting and easier plotting.

## Dimensionality reduction methods
| Method | Main idea |
|---|---|
| Principal component analysis | Unsupervised, projects onto directions of greatest variance |
| Linear discriminant analysis | Supervised, maximises class separation |
| t-SNE | Non-linear, preserves local structure for visualisation |
| UMAP | Non-linear, preserves local and global structure |

## How principal component analysis works
Centre the data by subtracting the mean of each feature. Calculate the covariance matrix. Use eigen-decomposition to get eigenvectors, which are the components, and eigenvalues, which show variance. Project the data onto the top components. If the first few components hold most of the variance, the features were highly redundant.
