# Reinforcement learning and Q-learning

## Reinforcement learning
In **reinforcement learning** an **agent** learns to make sequential decisions by interacting with an **environment** to reach a goal. The agent tries an action, the environment responds with a **reward** or a **penalty**, and over time the agent learns which actions give the best long-term outcome. For a self-driving car, the agent is the driving system and the environment is the road, other cars and traffic lights. Staying in lane is rewarded and a collision is penalised.

**Supervised learning** is given the right answer for each input in a fixed labelled dataset. Reinforcement learning is never told the right action. It only learns how good an outcome was, the reward can come later, and its own actions shape what it sees next.

> The agent is the learner that acts. The environment is everything outside it that gives the reward.

## Model-free and model-based
A **model-free** agent learns only from experienced transitions and rewards, without learning how the environment works. A chess AI that finds good openings by playing thousands of games is model-free. A **model-based** agent holds a model of the environment, with transition probabilities and rewards, and uses it to plan ahead. A robot vacuum that predicts the result of different routes before moving is model-based.

## Q-learning
**Q-learning** is a model-free, value-based method. The agent keeps a **Q-table** with one entry for each state and action pair. Each entry, Q(s, a), estimates the total future reward of taking action a in state s. The table starts at zero. A separate **reward table** holds the fixed immediate reward for each move.

The update rule is

Q(state, action) = R(state, action) + G x max Q(next state, all actions)

So the new value of a move is its immediate reward plus G times the best value available from the next state. **G**, typically 0.8, sets how much the future counts. If G were 0 the agent would only care about the immediate reward.

Values spread backwards from the goal. At first the agent moves at random. When it reaches the goal by chance, the move into the goal gets a strong value. On later episodes, the move before it sees that value in the next state and is strengthened too, and so on back to the start. Many **episodes** are needed, and the table has **converged** when its values stop changing.

A warehouse robot is a real example. The states are its locations, the actions are its moves, reaching the target gives a positive reward and hitting an obstacle gives a penalty.

> The reward table is fixed by the environment. The Q-table is learned and changes over time.
