# Reinforcement learning and Q-learning

## Reinforcement learning
An agent learns to make sequential decisions by interacting with an environment. It tries actions and the environment responds with a reward or a penalty. Learning is by trial and error, aiming at the best long term outcome. There are no labelled correct answers.

## Example of a self-driving car
The agent is the driving system and the environment is the road, other cars and lights. Rewards are staying in lane and avoiding collisions. Penalties are collisions, hard braking and running red lights.

## Types of reinforcement learning
- Model-free learns from experienced rewards and does not learn how the environment works.
- Model-based uses a model with transition probabilities and a reward function to predict results and plan.
- Value-based estimates the expected future reward of states or actions and acts on those values. Q-learning is an example.
- Policy-based learns a policy directly, which maps a state to an action.
- Actor-critic combines value-based and policy-based learning. The actor learns the policy and the critic learns a value function to judge it.

## Q-learning
Q-learning is model free and value based. The agent learns the best action in each situation from experience.

## The reward table and the Q-table
The reward table gives the immediate reward for moving between states. The Q-table stores learned values. Each entry is the expected total reward for taking an action in a state and then following the best policy. The Q-table starts at zero.

## How a Q-value is updated
A Q-value equals the reward of the current move plus a learning parameter, typically 0.8, times the best value available from the next state. The learning parameter sets how much future value counts. If it were zero, only immediate reward would matter.

## How learning spreads backwards from the goal
Early moves are random. By chance the agent reaches the goal and the move into the goal is strengthened. Next, the move before it is strengthened, and so on backwards. This repeats over many episodes until the values stabilise. That is convergence.
