# Reinforcement learning and Q-learning

## Reinforcement learning

**What it is.** Reinforcement learning is a branch of machine learning in which an agent learns to make sequential decisions by interacting with an environment to reach a goal. The agent tries actions, the environment responds with a reward or a penalty, and over time the agent learns which actions give the best long-term outcome.

**How it works.** The agent tries an action. The environment answers with feedback. The agent uses that feedback to improve its strategy for choosing actions. Learning comes from trial and error. The agent is aiming at the total reward over time, so an action with a small immediate payoff can still be the right one if it leads to bigger rewards later.

**Example.** A self-driving car has the driving system as its agent. The environment is the road, other cars, lanes and traffic lights. The goal is to drive safely to the destination. Staying in lane, avoiding collisions and smooth driving are rewards. Collisions, hard braking, lane violations and running red lights are penalties. A robot learning to walk and a chess program such as AlphaZero fit the same pattern. For the chess program the environment is the board and the opponent's moves.

**Easily confused with supervised learning.** Supervised learning is given the correct answer for each input in a fixed dataset. Reinforcement learning is never told the correct action. It only learns how good an outcome was, and it learns by acting, so its own choices shape what it experiences next.

**Common mistake.** Mixing up the agent and the environment. The agent is the learner that acts. The environment is everything outside it that responds with the reward.

## Model-free and model-based learning

**Model-free.** The agent learns from experienced transitions and rewards, without learning how the environment works and without knowing the probabilities of future outcomes in advance. A chess AI shows this. It repeats an opening move over thousands of games, finds that some openings tend to lead to winning positions, and gradually prefers them.

**Model-based.** The agent has a model of the environment, which holds transition probabilities and a reward function. It uses the model to predict what its actions will cause and to plan ahead, so it can think before it acts. A robot vacuum that predicts the result of different routes, avoiding obstacles and saving battery, before it moves is the example.

**Difference.** The question is whether the agent holds a model of how the world responds. The model-free agent learns only from what it has lived through. The model-based agent can look ahead inside its model.

## Value-based and policy-based learning

**Value-based.** The agent estimates the expected cumulative future reward of states or actions and picks actions with high values. A robot in an unknown maze learns by trial and error how valuable each move is. Q-learning is a value-based algorithm.

**Policy-based.** The agent learns a policy directly. A policy is a rule that says which action to take in a given state. An autonomous vehicle learning to steer, hold its lane and take bends safely is the example.

**Difference.** A value-based agent learns scores and then chooses by them. A policy-based agent learns the choice itself and skips the scoring step.

## Actor-critic

**What it is.** Actor-critic combines policy-based and value-based learning using two components that work together. The actor learns a policy and decides which action to take in each state. The critic learns a value function and judges how good the decisions or states are in terms of expected future reward.

**Example.** A humanoid robot learning to walk. The actor decides how to move the legs and the critic judges how well those movements contribute to walking without falling.

## Q-learning

**What it is.** Q-learning is a model-free, value-based method. The agent learns the best action for each situation by trying actions and learning from the rewards. It does not need to know how the environment works.

**What the Q-table stores.** The Q-table is a lookup table of learned values. Each entry is for one action taken in one state. It holds the expected total reward from taking that action in that state and then following the best policy afterwards.

**Reward table against Q-table.** The reward table holds the immediate feedback for moving from one state to another, and it is fixed by the environment. The Q-table holds learned long-term value, and it starts at zero and changes as the agent learns.

## How a Q-value is updated

**The rule.** The new value for a move equals the reward for that move plus G times the best value available from the next state. The reward table supplies the reward. The Q-table supplies the best next value.

**The role of G.** G is called the learning parameter, typically 0.8, and it sets how much future value counts. Textbooks call the same quantity the discount factor. If G were zero, only the immediate reward would matter and the agent would be short-sighted. A larger G makes the agent care more about later rewards.

**Why learning spreads backwards.** Every value starts at zero, so early moves are random and tell the agent nothing. Only when the agent happens to reach the goal does it see a reward. That strengthens the move into the goal. On a later episode, the move before the goal can see that strengthened value in the next state, so it gets strengthened too. The move before that follows, and so on back to the start. In the worked example, the move into the goal state carries a reward of 100 and the move just before it takes a share of that, so the values shrink with distance from the goal.

**Convergence.** The table is built step by step over many episodes of interaction. When the values stop changing, the table has converged. Many episodes are needed because each pass pushes the value back only one step.

**Common mistake.** Thinking a random start means nothing can be learned. The agent reaches the goal by chance and the update rule passes that value back.
