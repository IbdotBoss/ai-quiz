# Natural language processing

## What NLP is
**Natural language processing**, NLP, is a branch of machine learning and AI that derives meaning from human language and handles it automatically. It covers speech and text. Its uses include chatbots, sentiment analysis of reviews, fake news detection, translation, question answering, summarising and speech recognition. **Natural language understanding** works out what a sentence means. **Natural language generation** turns a formal statement into natural language. The lecture's running example is a spam filter for text messages.

## Preparing text
Raw text is cleaned before a model sees it.

1. **Remove irrelevant characters** such as punctuation, hashtags, HTML tags and encoding symbols. `<p>Hey there!!!</p> #Excited` becomes Hey there Excited.
2. **Normalise case** by lowercasing, since casing tells little about sentiment. SIX chances to win CASH! becomes six chances to win cash!.
3. **Tokenize**, splitting sentences into tokens, usually words but sometimes subwords or characters. **N-grams** are sequences of N tokens in a row that capture context.
4. **Remove stop words**, common words such as and, to and the that add little meaning.
5. **Stem or lemmatize**. **Stemming** cuts prefixes and suffixes by rule, so happily and happiness both become happi, which is not a word. **Lemmatization** uses meaning to give the dictionary form, so went becomes go and better becomes good.

> Stemming can give non-words. Lemmatization always gives a real word.

## Turning text into numbers
Models do maths on numbers, so text is **vectorised**. Techniques include bag of words, one-hot encoding and TF-IDF.

**TF-IDF** shows how important a word is to one document within a collection, the corpus. TF is how often the term appears divided by the number of terms in the document. IDF is ln of the number of documents over the number that contain the term. With 200 documents, 8 containing aid, and a 4-term document containing aid once:

- TF = 1 / 4 = 0.25
- IDF = ln(200 / 8) = 3.21
- TF-IDF = 0.25 x 3.21 = about 0.80

A word frequent in one document but rare across the corpus scores high. TF-IDF vectors are **sparse**.

**Word embeddings** are **dense** vectors of continuous values that capture meaning, so words used in similar contexts, such as king and queen, get similar vectors. Word2Vec, GloVe and FastText are pre-trained embeddings. An **embedding layer** inside a network turns words into dense vectors, replacing inefficient sparse one-hot vectors.

## Why word order matters
A model built on word frequencies ignores order, but order and context change meaning, and that car is sick could be praise or a complaint. So the text is turned into number **sequences**, for example with `texts_to_sequences`, which keeps the word order. RNNs and LSTMs need a fixed input size, so `pad_sequences` pads or truncates every sequence to the same length. The sequences pass through an embedding layer into an RNN or LSTM.

> Padding fixes the length of each sequence. The embedding layer turns each word into a dense vector.
