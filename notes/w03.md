# Supervised regression

## Supervised learning
Supervised learning trains a model on labelled historical data. Each example has input features, also called independent variables or predictors, and an output label, also called the dependent variable or target. The model then predicts for new, unseen data.

## Regression and classification
Regression predicts a continuous number, such as a price, a temperature or energy demand. Classification predicts a discrete class, such as spam or not spam. Classification can return class probabilities and a threshold turns them into a label. Regression returns a numeric estimate directly. A count, such as tickets raised tomorrow, is still treated as a regression target.

## Regression evaluation metrics
Evaluation checks how far predicted values are from actual values.
- Mean absolute error is the average absolute difference between predicted and actual values. It is less sensitive to outliers.
- Mean squared error squares the errors, so large mistakes are penalised more.
- Root mean squared error is the square root of that, so it is in the same units as the target. It is still sensitive to outliers.
- R-squared shows how much of the variance in the target the model explains. A value of 1 is a perfect fit, 0 means no better than predicting the mean, and below 0 is worse than that baseline.

## Linear regression
It fits a straight line, or a flat surface for many inputs. Ordinary least squares chooses the coefficients that make the sum of squared residuals as small as possible. It works best when the relationship is roughly linear. It is used for baselines and when interpretable coefficients matter.

## Random forest regression
It is an ensemble of many decision trees. Each tree is built on random rows and features. Each tree predicts a number and the forest returns the average. Averaging makes it more stable than one tree. It handles non-linear data, is robust to outliers and is less prone to overfitting.

## Comparing three regression models
| Regression model | Strength | Weakness |
|---|---|---|
| Linear regression | Simple and interpretable | Needs a roughly linear relationship |
| Random forest | Handles non-linear data and outliers | Harder to interpret |
| Gradient boosting | Builds trees in sequence to fix earlier errors | Trees depend on each other, so they are built in order |

Random forest is a bagging method, with independent trees averaged. Boosting builds trees one after another. Support vector regression suits medium-sized datasets with complex relationships.
