# Regression

## Regression and classification
**Regression** predicts a continuous number, such as tomorrow's electricity use in kilowatt hours, a price or a temperature. **Classification** predicts a category. Both are supervised, so the model learns from labelled examples with input **features** and a target **label**.

> A count, such as the number of support tickets tomorrow, is a number on a scale, so it is regression.

## Linear regression
**Linear regression** assumes the target can be written as a linear equation of the inputs. Each feature gets a **coefficient** for its contribution, plus an **intercept**. For any candidate line, each point has a **residual**, the gap between the predicted and actual value. **Ordinary least squares** picks the coefficients that make the **sum of squared residuals** as small as possible. Squaring stops positive and negative gaps cancelling and gives large gaps extra weight.

Its advantages are simplicity, low computational cost and **interpretability**, since each coefficient shows how an input changes the prediction. Its limits are that it fits poorly when the relationship is curved, and it is sensitive to outliers and to multicollinearity.

> Fitting only a straight line to a curved relationship breaks the linearity assumption.

## Measuring a regression model
- **Mean absolute error**, MAE, is the average size of the errors. Every error counts in proportion, so it is less sensitive to outliers.
- **Mean squared error**, MSE, squares each error before averaging, so a few large errors raise it sharply.
- **Root mean squared error**, RMSE, is the square root of MSE and is in the same units as the target, so it is easier to explain.
- **R squared** shows how much of the variation in the target the model explains. 1 is a perfect fit. 0 means no better than always predicting the mean. Below 0 means worse than that.

> MSE reacts most to a few very large errors. MAE treats them more fairly.

## Random forest regression
A **random forest** builds many decision trees, each on a random sample of rows and features, and averages their predictions. Each tree makes different mistakes, so averaging cancels much of the error. This makes it more stable than one tree, robust to outliers and able to follow nonlinear patterns. It is harder to interpret than linear regression. **Gradient boosting** also uses many trees, but builds them one after another, each fixing the errors of the ones before.

> Random forest trees are independent and averaged. Boosting trees are sequential.
