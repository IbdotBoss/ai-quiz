# Supervised learning and regression models

## Supervised learning

**What it is.** Supervised learning trains a model on labelled historical data so that it can predict the outcome for new cases it has not seen. Each training example has input features, also called independent variables or predictors, and an output label, also called the dependent variable or target.

**How it works.** The model studies many past examples where the answer is already known. It learns the link between the features and the label, then applies that link to fresh inputs. The model can compare each guess with the known answer.

**Example.** A housing dataset has columns for square feet, bedrooms, bathrooms and location score. These are the features. The price column is the label, because price is the thing the model must predict. 

**Easily confused with.** Reinforcement learning also learns from feedback, but its feedback is a reward from trial and error and there are no labelled answers. Unsupervised learning has no label at all.

## Regression and classification

**What it is.** Regression predicts a continuous number, such as a price, a temperature or demand. Classification predicts a discrete class, such as spam or not spam. Both are supervised.

A classification model can return class probabilities, and a threshold turns a probability into a label. A regression model returns a numeric estimate directly.

**Example.** Deciding from a chest X-ray whether a patient has pneumonia is classification. Forecasting the travel time in minutes from Cambridge to London is regression. Sorting customers into new, active or churn-risk is classification with three classes.

**Common mistake.** Treating a count as a class. The number of support tickets raised tomorrow is a quantity on a scale, so it is a regression target even though it takes whole values.

## Regression evaluation metrics

**What it is.** Evaluating a regression model means measuring the distance between the predicted values and the actual labels. A smaller distance means a better model. Four metrics are common.

**Mean absolute error.** This is the average size of the gaps between predicted and actual values, ignoring direction. Each gap counts in proportion to its size, so the metric is less sensitive to outliers. It suits cases where occasional extreme values are noise and a fair typical error is wanted.

**Mean squared error.** This squares each gap before averaging. Squaring makes one large mistake count far more than several small ones, so the metric punishes big errors strongly. It suits cases where a few large misses are especially costly.

**Root mean squared error.** This is the square root of mean squared error. Taking the root brings the answer back to the same units as the target, so it is easier to interpret. It stays sensitive to outliers because the squaring has already happened.

**R-squared.** This is the coefficient of determination. It shows how much of the variance in the target the model explains. A value of 1 is a perfect fit and closer to 1 is better. A value of 0 means the model does no better than always predicting the mean of the actual values. A value below 0 means the model is worse than that baseline.

## Linear regression

**What it is.** Linear regression fits a straight line through the data, or a flat surface when there are several inputs. The line has coefficients, which are the intercept and the slopes, and fitting means finding good values for them.

**How it works.** For any candidate line, each data point has a residual, which is the gap between the value the line predicts and the actual value. Ordinary least squares picks the coefficients that make the sum of the squared residuals as small as possible. Squaring stops positive and negative gaps from cancelling each other and gives large gaps extra weight. The result is the line closest to the data in the least squares sense.

**When it is used.** It works best when the relationship is roughly linear. It is the usual baseline model, and it is chosen when interpretable coefficients matter, for instance when a regulator wants to see how each input changes the predicted price.

## Random forest regression

**What it is.** A random forest is an ensemble of many decision tree regressors. Each tree is built on random rows and random features, and the forest predicts by averaging the numbers its trees produce.

**How it works.** Because every tree sees a different random slice of the data, the trees differ from one another. For a new case each tree predicts a number, and the forest returns the average. One tree can be thrown off by quirks in its own training sample. Different trees make different mistakes, so averaging cancels much of the error and gives a more stable answer. This also makes the forest robust to outliers and less prone to overfitting.

## Gradient boosting and other models

**What it is.** Gradient boosting regression, such as XGBoost, also uses many trees, but it builds them one after another. Each new tree is trained to fix the errors left by the trees before it.

**Random forest against boosting.** A random forest is a bagging method. Its trees are independent, built side by side, and averaged. Boosting is sequential, so every tree depends on the one before. Both are tree ensembles, which is why they are easy to mix up.

Support vector regression extends support vector machines to regression and suits medium-sized datasets with complex relationships.

## Choosing between models

Linear regression is simple and interpretable, but it needs a roughly linear relationship. Random forest copes with non-linear patterns and outliers, but it is harder to interpret. Choose linear regression when a simple, explainable model is needed and the relationship looks linear. Choose a random forest when the data is complex and non-linear and accuracy matters more than a clear formula.

## Why regression matters in research

Regression quantifies how much each input affects an outcome, predicts continuous values for forecasting and tests assumptions about cause and effect. Its coefficients are interpretable and many advanced models build on it.
