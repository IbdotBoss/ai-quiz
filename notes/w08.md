# Convolutional Neural Networks

## Why CNNs exist
Traditional fully connected networks are good classifiers but poor at feature extraction. Image meaning sits in groups of neighbouring pixels. A CNN assumes the input is an image, so it can use these local features.

## Convolution and filters
A filter or kernel is a small 2D array of weights. It slides over the image and multiplies with each patch. Different filters find edges, corners and other features. Filters start random and are improved by training. The usual size is 3 by 3.

## Stride and padding
Stride is how far the kernel shifts each step. A larger stride gives a smaller output. Padding adds a border so edge pixels are handled. Zero padding is common. Reflection and replication padding are alternatives.

## Pooling
Pooling shrinks the feature maps and saves computation. Max pooling keeps the largest value in each patch. Average pooling keeps the mean.

## Activation
An activation function is a gate between a neuron's inputs and its output. ReLU is the most popular in CNNs.

## Normalisation
Scaling features keeps their magnitudes similar. Batch normalisation uses the mean and standard deviation of each feature across a mini batch. It reduces covariate shift and speeds up learning.

## Dropout and overfitting
Overfitting means tiny training error but large error on new data, because the network has memorised the examples. Dropout randomly ignores some layer outputs during training, which acts as regularisation.

## Fully connected layers
| Layer | Job |
|---|---|
| Flatten | Turns feature maps into one vector |
| Normal | Applies weights and biases |
| Softmax output | Turns logits into probabilities that sum to one |

## Whole picture
Stage one uses convolution, pooling and dropout to find features. Stage two uses fully connected layers to predict the label.
