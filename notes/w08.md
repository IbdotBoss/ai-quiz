# Convolutional neural networks

## Why ordinary networks struggle with images
**What it is.** A traditional fully connected network is a good classifier but a poor feature extractor, and it does not scale well to images. A convolutional neural network, or CNN, instead assumes that its input is an image.

**Why it matters.** The meaning of an image sits in groups of neighbouring pixels that together form a shape. One pixel on its own means almost nothing. A traditional network is not designed to use these local groups. A CNN builds the image assumption into its structure, so it can use local features. That makes feature extraction stronger and the whole network more efficient.

**Confused with.** A CNN is still made of neurons with learnable weights and biases. Each neuron takes a dot product and may follow it with a non-linearity. What changes is the image assumption, not the neuron.

## Images and channels
Every image is a matrix of pixel values from 0 to 255. A channel is one colour component of the image. A colour image has three channels, red, green and blue, like three 2D matrices stacked on top of each other. A grayscale image has one channel.

## Convolution and the filter
**What it is.** Convolution is a linear operation that multiplies a 2D array of weights, called a filter or kernel, with a patch of the 2D input image. It extracts and keeps the local features of the image.

**How it works.** The filter slides across the image. At each position it multiplies its weights with the pixels beneath it to produce one output value. The output is smaller and easier to process, yet it still holds the features that matter for a good prediction. Different filters detect different features, such as edges, points and corners, or they sharpen or soften the image. The most common filter size is 3 by 3. For an RGB image the filter works over all three channels. Textbooks add that the filter has one layer of weights per channel and combines the results into a single output value.

**Why filters work.** Filters start with random values, just like weights and biases in a traditional network. Many rounds of feedforward and backpropagation then turn them into powerful feature detectors.

**Common mistake.** Thinking that someone designs the filters by hand. In a CNN they are learned during training.

## Stride and padding
**Stride.** Stride is the amount the kernel shifts each step. It moves right by the stride until it covers the full width, then returns to the left, drops down by the same stride and repeats. A stride of 2 visits fewer positions than a stride of 1, so the output is smaller.

**Padding.** The edges of the image are awkward, because edge pixels have fewer neighbours for the kernel to cover. Padding adds a border around the image to handle them. Zero padding fills the border with zeros. Reflection padding and replication padding fill it with copies of nearby pixel values instead. Textbooks add that padding also lets the output stay close to the input size.

**Confused with.** Stride changes how far the kernel moves. Padding changes what surrounds the image. Neither changes the filter weights.

## Pooling
**What it is.** A pooling layer reduces the spatial size of the convolved features. This lowers the computing power needed. It also picks out dominant features that do not depend much on position or rotation, which helps the model train well.

**Two types.** Max pooling returns the largest value in the patch under the kernel. Average pooling returns the mean of all values in that patch.

**Confused with.** Max pooling keeps only the strongest response. Average pooling gives a smoother summary of the whole patch. Both shrink the map.

## Activation
**What it is.** An activation function is a mathematical equation that decides a neuron's output. In a CNN it works across two dimensions like a screen and decides whether each output pixel is activated. It is a gate between the inputs feeding a neuron and the output going to the next layer.

**Why.** Textbooks add that without a non-linear activation the network could only learn simple linear relationships. ReLU is the most popular choice in CNNs. Textbooks describe it as passing positive values and setting negative ones to zero.

## Normalisation
**Input scaling.** Features are scaled to a fixed range, for example 0 to 1. This keeps the size of every feature's contribution to the prediction about the same.

**Batch normalisation.** Suppose two batches look very different from each other. The data distribution then shifts a lot, which is called covariate shift. The network is misled into adjusting its weights towards one odd batch, so it bounces back and forth between distributions and trains slowly. Batch normalisation works on feature maps across a mini batch. For each feature it finds the mean and variance, subtracts the mean and divides by the standard deviation. This speeds up learning and gives faster convergence.

**Confused with.** Input scaling happens once to the raw data. Batch normalisation happens inside the network, batch by batch.

## Overfitting and dropout
**Overfitting.** The training error becomes very small, but the error on new data is large. The network has memorised the training examples and has not learned to generalise.

**Dropout.** Dropout is a simple regularisation technique that helps prevent overfitting. During training, some layer outputs are randomly ignored. The layer then looks like a layer with a different number of nodes and connections from the one in the previous pass. The network cannot lean on any one path, so it cannot simply memorise the whole training set. One description of dropout is that it throws away some training samples in each iteration. Textbooks put it as randomly ignoring some neuron outputs, and that is the version to use as a definition.

**Common mistake.** Thinking dropout is meant to help memorise the data. It does the opposite. The dropped outputs also come back on later passes, so they are not removed for good.

## Fully connected layers
A CNN has two main stages. First, convolution, pooling and dropout break the image into features and analyse them. Then one or more fully connected layers take those features and predict the best label.

| Layer | Job |
|---|---|
| Flatten | Turns the feature maps into a single vector that the next stage can take as input |
| Normal fully connected | Applies weights and biases to the features |
| Softmax output | Turns feature values, called logits, into a probability for each label, and the probabilities sum to one |

## The layers in order
A CNN uses six layer types, which are convolutional, pooling, activation, normalisation, dropout and fully connected. They are stacked in a certain order to shrink the image while keeping the features that tell classes apart. An image passes through the feature stage, then the flatten layer, then the fully connected layers, and softmax gives the final label probabilities.
