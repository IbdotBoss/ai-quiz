# Convolutional neural networks

## Why CNNs for images
A traditional fully connected network is a good classifier but a poor feature extractor, and it does not scale well to images. It flattens the image and connects every pixel to every neuron, which needs very many weights and loses the layout of the picture. The meaning of an image sits in groups of neighbouring pixels. A **convolutional neural network**, CNN, assumes its input is an image and exploits these **local features**, so it extracts features better and scales to images.

## The components
A CNN has two stages. The feature stage breaks the image into features, and the classification stage predicts the label.

- A **convolutional layer** slides small **filters**, also called kernels, over the image. At each position the filter multiplies its weights with the pixels under it to give one value, building a **feature map**. Different filters detect edges, corners and textures. Filters start random and are learned in training. 3 x 3 is the most common size.
- **Stride** is how far the filter moves each step. A stride of 2 gives a smaller output than a stride of 1. **Padding** adds a border, often zeros, so edge pixels are covered and the output can stay close to the input size.
- An **activation layer**, usually **ReLU**, adds nonlinearity by passing positive values and setting negative ones to zero.
- A **pooling layer** shrinks the feature maps to save computation and keep the strongest features. **Max pooling** keeps the largest value in each window. Average pooling keeps the mean. Pooling also keeps dominant features that do not depend on position or rotation, which helps training.
- **Batch normalisation** subtracts the mini-batch mean of each feature and divides by its standard deviation, then applies a learned scale and shift. This handles covariate shift between batches and speeds up training.
- A **dropout layer** randomly ignores some neuron outputs during training so the network cannot memorise the training data, which reduces **overfitting**.
- **Fully connected layers** come last. A flatten layer turns the feature maps into one vector, and a **softmax** output gives a probability for each class.

## Two calculations
The output size of a convolution is (input - kernel + 2 x padding) / stride + 1. A 32 x 32 input with a 3 x 3 kernel, stride 1 and no padding gives (32 - 3) / 1 + 1 = **30 x 30**.

Max pooling 2 x 2 on [2, 7; 5, 3] gives **7**, the largest value. Average pooling would give 4.25.

> Overfitting means a tiny training error and a large error on new data. Dropout helps prevent it.
