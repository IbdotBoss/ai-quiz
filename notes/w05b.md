# Genetic algorithms

## What a genetic algorithm is

**What it is.** A genetic algorithm is a method for solving constrained and unconstrained optimisation problems. It imitates natural selection, where the fittest survive. It was developed by John Holland in the 1970s.

**How it works.** It keeps a population of candidate solutions and does not improve just one. At each step it selects individuals from the current population according to their fitness and uses them as parents to produce children for the next generation. Over many generations the population evolves toward an optimal solution. Finding the optimum is a by-product of the evolving process.

**Example.** A genetic algorithm suits large search spaces such as scheduling, route optimisation and finance, where checking every option would take far too long.

**Common mistake.** Describing it as improving one solution step by step. It improves a whole population at once.

## Terms borrowed from biology

In biology, chromosomes are strings of DNA inside each cell. Genes are blocks of DNA inside a chromosome, and each gene decides some aspect of the organism, such as eye colour. Crossover is the recombination of genes from parents. Mutation is an error in copying a gene. Fitness is the success of an organism.

In the algorithm, a chromosome is one candidate solution, written as a string. A gene is one unit of that string. Fitness is how good the solution is, and it decides which solutions are kept.

**Example.** A candidate solution is stored as a bitstring such as 101110. The whole bitstring is the chromosome. Each single bit, 0 or 1, is a gene. The bitstring is decoded into a number, here a whole number between 0 and 63, and that number is the proposed answer to test. This is what representing a solution means.

**Common mistake.** Calling the whole string a gene. The whole string is the chromosome and one bit is the gene.

## Crossover against mutation

**Crossover.** This takes parts of two parent chromosomes and joins them to make a child, like parents passing on a mixture of their DNA. It reuses good features already in the population.

**Mutation.** This makes a small random change to one chromosome, such as flipping one bit, like a copying error. It can bring in variety that no existing solution contains.

**Why both are used.** Crossover alone can only shuffle what the population already has. Mutation adds new material, so the search can reach places the starting population never covered. Used together, the algorithm keeps what works and still explores. A common mix in one generation is a few crossovers and a couple of mutations.

**Easily confused.** Crossover needs two parents. Mutation changes one chromosome.

## The steps of the loop

1. Create an initial population of random solutions. A random start gives a spread of guesses across the search space.
2. Test each solution for fitness and rank them. Ranking shows which solutions are worth keeping.
3. Remove some bad solutions and duplicate some good ones, so the next generation leans toward better answers.
4. Make small changes to the good solutions using crossover and mutation, to create new candidates.
5. Repeat from step 2 until the best solution is good enough.

Problems are usually set up as finding a minimum, because a lower value then means a better solution. Other problems are reformulated as minimisation so that the same loop can run on them.

## Why other methods fall short

**Analytical method.** If the relationship can be written as an equation, differentiating it gives the gradient. The minimum sits where the gradient is zero. This fails when the relationship cannot be expressed as an equation, when it has several minima, or when the real-world problem has many variables and constraints.

**Blind generate and test.** This is a numerical method. It guesses a possible solution, tests how good it is, and repeats until one is good enough. Each guess ignores the earlier ones. It may take too long to converge and may be misled by several minima.

**How a genetic algorithm helps.** It also generates and tests, but the search is guided. It ranks solutions, keeps and copies the good ones and varies them, so each generation builds on earlier results. It needs no equation.

**Easily confused.** Blind generate and test and a genetic algorithm both test many solutions. Only the genetic algorithm uses what it has learned to choose the next candidates.

## Strengths and limits

An advantage is that approximate solutions can usually be found. A disadvantage is that it can be hard to represent a problem as a genetic problem. The problem has to be encoded as chromosomes and given a fitness measure before the algorithm can run. The method suits large search spaces.
