# Recurrent Neural Networks

## Sequential data
Some tasks treat each example on its own, such as classifying iris flowers. In others the order matters, such as translation, speech recognition, handwriting recognition, video prediction and time series. The same words in a different order can mean the opposite.

## RNN and hidden state
An RNN adds a recurrent connection that forms a cycle. The hidden state is a representation of previous inputs, passed forward. At each step the current input is joined to the previous hidden state and passed through an activation function. The result goes to the output and is also copied to the next step.

## Vanishing gradient
In backpropagation each gradient depends on the layer after it, so gradients shrink exponentially going back. Early layers barely learn. In an RNN this gives short term memory.

## Backpropagation through time
The forward pass computes the estimate and the total loss. The backward pass sends the loss back and uses the chain rule to change weights.

## Truncated backpropagation
It looks back over only a moving window. It is faster and simpler, but it cannot learn dependencies longer than the window.

## LSTM
An LSTM learns long term dependencies. The cell state runs along the chain like a conveyor belt. Gates use a sigmoid and pointwise multiplication, with zero meaning nothing passes and one meaning everything passes.
- Forget gate throws away old information.
- Input gate and candidate values add new information.
- Output step filters the cell state with tanh and a sigmoid gate.

## GRU
| | LSTM | GRU |
|---|---|---|
| Gates | More | Update and reset |
| Computation | More | Less |

A GRU is a simplified LSTM.
