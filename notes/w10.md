# Recurrent neural networks

## Why order matters
In some tasks each example stands alone, such as classifying an iris flower from four measurements. In others the **order** of the data carries meaning, such as speech recognition, translation, handwriting and time series. The cat killed the dog and the dog killed the cat use the same words with opposite meanings.

## How a simple RNN works
A **recurrent neural network**, RNN, processes a sequence one step at a time. A feedforward network or CNN only passes information from one layer to the next. An RNN adds a **recurrent connection** that forms a loop. At each step the hidden node combines the current input with the **hidden state** from the previous step, passes the result through an activation function, and sends a copy forward as the new hidden state. The hidden state is the network's memory of earlier inputs. Unfolding the loop shows the same cell repeated once for each time step. To classify a sentence, the RNN reads it word by word and passes its final output to a feedforward layer.

## The limit, vanishing gradients
An RNN is trained with **backpropagation through time**. The forward pass runs through the sequence and computes the loss, and the backward pass sends the error back across the time steps. Each step's gradient depends on the gradient of the step after it. Going back, the gradient is multiplied by small values again and again, so it shrinks exponentially. This is the **vanishing gradient** problem. The earliest steps barely learn, so the RNN has **short-term memory** and struggles with **long-term dependencies**. To finish I grew up in France and I speak fluent, it needs France from far back.

**Truncated backpropagation through time** only looks back over a fixed window of steps. It is faster, but it cannot learn dependencies longer than the window.

> The gradient shrinks toward zero, so the early steps stop learning.

## How an LSTM fixes it
A **long short-term memory** network, LSTM, is a special RNN built to remember for long periods. A standard RNN cell has a single layer, while an LSTM cell has four interacting layers. It adds a **cell state** that runs along the whole chain like a conveyor belt, with only minor linear interactions, so information can pass along unchanged. **Gates** control it. Each gate is a sigmoid layer, giving values from 0 to 1, and a pointwise multiplication.

1. The **forget gate** looks at the previous hidden state and current input and decides how much of the old cell state to keep. 1 keeps it and 0 removes it.
2. The **input gate** decides which values to update, and a tanh layer creates new candidate values, which are added to the cell state.
3. The **output gate** decides which parts of the cell state, passed through tanh, become the output.

A **GRU** is a simpler variant with only an update gate and a reset gate, so it needs less computation.

> Forget removes old information, input adds new information and output filters what is shown.
