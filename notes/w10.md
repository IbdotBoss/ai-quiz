# Recurrent neural networks

## Sequential data
**What it is.** In some tasks each example stands alone and no history is needed. Classifying an iris flower from its four measurements is one. In other tasks the order of the data matters and it helps to know what came before and after. Examples are natural language processing, speech recognition, machine translation, handwriting recognition, video sequence prediction and time series.

**Why order matters.** The cat killed the dog and the dog killed the cat use the same words with opposite meanings. A video example makes the same point. One frame of a ball cannot show which way it is moving, but many frames in succession give enough information to predict its direction.

**Confused with.** Ordinary feedforward networks and CNNs treat each input on its own. Textbooks add that this is why they cannot use order.

## How an RNN remembers
**What it is.** A recurrent neural network, or RNN, is a family of networks for sequential and temporal problems. A feedforward network or CNN only has connections from one layer to the next. An RNN adds a recurrent connection that forms a cycle.

**How it works.** The loop passes prior information forward. That information is the hidden state, a representation of previous inputs. At each time step the node joins the current input to the old hidden state, which is called working memory, and passes the result through an activation function. The output goes onward to the output layer, and a copy goes to the next step as the new working memory. So the input at time t depends on the current input and on the hidden state, which itself depends on earlier inputs. The folded view shows one node with a loop. The unfolded view shows the same node repeated once for each time step.

**Example.** To read a sentence, split it into words. The RNN encodes the first word and gives an output. The next word is fed in along with the hidden state from the previous step. This repeats until the last word. By then the hidden state holds information from all the earlier words. The final output can be passed to a feedforward layer to classify the intent of the sentence.

**Common mistake.** Thinking that the hidden state is the same as the output. The output is also sent to the next step, but the hidden state is the memory carried through time.

## Vanishing gradient
**What it is.** The vanishing gradient problem is the cause of short-term memory in an RNN. As it processes more steps, it has trouble keeping information from earlier steps.

**Why it happens.** In backpropagation each node works out its gradient from the effects of the layer after it. If the adjustments there are already small, the adjustment for the current layer is even smaller. So gradients shrink exponentially as they travel back. The earliest layers receive tiny gradients, their weights barely change and they learn almost nothing. It is common in very deep feedforward networks as well as in RNNs.

**Example.** In a long sentence, the first words have little influence on the final hidden state.

**Common mistake.** Thinking that the gradient grows or that the network crashes. The gradient becomes tiny, so learning stalls.

## Backpropagation through time
Training an RNN uses a loss function that measures the error between the true label and the predicted label. The aim is to minimise it with a forward pass and a backward pass. In the forward pass the input goes through the hidden states and the estimated label is calculated. The loss is computed to see how far it is from the true label, and the total loss L completes the pass. In the backward pass the total loss is propagated back through the network. Partial derivatives and the chain rule show how much each weight should change. It is called through time because the error travels back across the time steps.

## Truncated backpropagation through time
**What it is.** Normal backpropagation through time goes back through the entire sequence, which causes the gradients to vanish. Truncated backpropagation through time only looks back over a moving window of time steps.

**Benefit.** It is much faster and less complex, because gradients from faraway steps are not included.

**Drawback.** Dependencies longer than the window cannot be learned. Take the sentence I grew up in France and I speak fluent French. The recent words suggest a language. To narrow it down, the network needs France from much further back. If the gap is larger than the window, the clue is out of reach. That is why it may not be an ideal solution.

## LSTM
**What it is.** A long short-term memory network is a special kind of RNN that can learn long-term dependencies. It is designed to remember information for long periods. A standard RNN has a single layer in its repeating unit, while an LSTM has four interacting layers.

**Cell state.** The cell state is the horizontal line running through the cell like a conveyor belt. It runs straight along the whole chain with only minor linear interactions. Textbooks add that this is why useful information and gradients can survive over long sequences, where a simple RNN fades.

**Gates.** A gate lets information through only in part. It is built from a sigmoid layer and a pointwise multiplication. The sigmoid gives numbers from zero to one for each component. Zero means let nothing through and one means let everything through. The LSTM uses gates to add or remove information from the cell state.

**Step one, forget.** The forget gate is a sigmoid layer that looks at the previous hidden state and the current input. For each number in the cell state it gives a value from 0 to 1. A 1 means keep it completely and a 0 means get rid of it completely.

**Step two, store.** The input gate is a sigmoid layer that decides which values to update. A second layer creates a vector of new candidate values that could be added. Together they make an update, which is combined with the old cell state to form the new one.

**Step three, output.** The output is a filtered version of the cell state. A sigmoid layer decides which parts to output. The cell state goes through tanh, which pushes the values between minus 1 and 1, and is multiplied by the sigmoid output so only the chosen parts come out.

**Common mistake.** Mixing up the roles. Forget removes old information, input adds new information and output filters what is shown.

## GRU
A gated recurrent unit is a simplified variant of the LSTM. It has fewer gates, only an update gate and a reset gate. It still models temporal patterns efficiently and needs less computational power.

| | LSTM | GRU |
|---|---|---|
| Gates | Forget, input and output | Update and reset |
| Cost | More computation | Less computation |

**Confused with.** Both are gated and both address the vanishing gradient problem. The GRU is the lighter one. Textbooks add that a GRU has no separate cell state.
