## The brain and the artificial neuron

**What it is.** A biological neuron receives impulses through its dendrites, passes them through its nucleus and axon, and releases them at the axon terminal to neighbouring neurons. An artificial neuron copies this layout at a small scale, with inputs in place of dendrites and an output in place of the axon.

**Why.** Early AI researchers wanted machines to learn like humans, and the brain was the one working example. The imitation is loose, keeping only the idea of many simple connected units passing signals on.

## The perceptron and its activation function

**What it is.** A perceptron is the simplest neural network, a single neuron with several input nodes and one output node.

**How it works.** Each connection leaving an input node carries a weight, which sets how strongly that input counts. The neuron multiplies every input by its weight and adds up the products. It then adds a bias, which shifts the total whatever the inputs are. Last, the activation function looks at the total and decides whether the neuron fires. The step function gives one of two values, 0 or 1. Sigmoid and softmax are other common choices. Weights and bias start random.

**Example.** The course example has three inputs with a weight each, plus a bias. The total is large enough that the step function outputs 1.

**Easily confused.** The weight scales one input, the bias is added once to the total, and the activation function makes the fire decision. Saying the weight decides whether the neuron fires is a common mistake.

## One perceptron and layered networks

A single perceptron can only learn linearly separable patterns, where one straight boundary splits the classes. XOR is the usual example it cannot learn. A network joins thousands of perceptrons in consecutive layers, and together they turn the input data into predictions based on features being present or absent. Textbooks add that the extra layers are what remove the linear limit.

**A common mistake.** Believing more epochs will let one perceptron learn XOR. The limit comes from its structure.

## Supervised learning

**What it is.** In supervised learning the correct output for each training sample is known in advance. The aim is to learn a function that best matches inputs to outputs. Neural networks generally learn this way.

**Example.** In the iris dataset each flower has four measurements, sepal and petal length and width, plus a flower type. The measurements are the features the network reads. The flower type is the label it learns to predict.

**A common mistake.** Listing the label as an input, or thinking known answers remove the need for a cost function. The network still needs to measure how far its predictions are from them.

## Initialisation

Before training, every weight and bias is set to a random value, so the first prediction is random and nothing has been optimised. The course sums this up as garbage in, garbage out. Textbooks add that identical values would make every neuron learn the same thing.

## The training loop

**What it is.** Training is an iterative loop. After random initialisation each round has four steps.

- Feed forward from the input layer to the output layer to make a prediction.
- Apply the cost function to measure the error, which needs a prediction to exist first.
- Backpropagate the error to each layer so each layer's share is known.
- Use gradient descent to adjust the weights and biases and reduce the error.

The epoch counter then goes up. The loop stops when the cost converges or a maximum number of epochs is reached.

**Epoch.** The course counts one round of this loop as an epoch. Textbooks define an epoch as one pass over the whole training set.

**A common mistake.** Putting the steps in the wrong order, such as updating weights before the error has been measured.

## Cost and loss

**What it is.** A cost function measures the error between what the model predicts and the true label, and gives it as one real number. Training seeks parameters that make it as small as possible.

**Easily confused.** Loss usually refers to the error for one observation. Cost usually refers to the average of the loss over the training set. Reversing the two is a common mistake.

## Regression and classification costs

Regression predicts a number such as a house price. Classification predicts a class such as spam or not spam.

| Cost | Task | What it does |
|---|---|---|
| Mean squared error | Regression | Averages the squared differences between predictions and true values |
| Mean absolute error | Regression | Averages the size of the errors, ignoring direction |
| Root mean squared error | Regression | Textbooks define it as the square root of the mean squared error |
| Binary cross entropy | Classification with targets of 0 or 1 | Measures how far each prediction is from the true value and averages these |

**Mean squared error.** In this course the errors are described as growing exponentially with distance. Textbooks put it more exactly, saying the penalty grows with the square of the distance. Either way far predictions get a massive penalty and close ones a minimal penalty.

**Binary cross entropy.** It comes from information theory and asks how many bits are lost. It is the difference between two probability distributions, p the true one-hot label and q the predicted probability. The prediction usually comes from a sigmoid or softmax.

**A common mistake.** Pairing a cost with the wrong task, such as binary cross entropy for house prices.

## Gradient descent

**What it is.** Gradient descent finds which way to move the weights and biases to lower the cost. It uses the derivative, which is the slope of the cost at the current point. The sign of the slope gives the direction of the next move.

**Why the negative direction.** A positive slope means the cost rises as the weight rises, so the update lowers the weight. Repeating this lowers the cost step by step.

**Easily confused.** Backpropagation and gradient descent do different jobs.

| Process | Job |
|---|---|
| Backpropagation | Sends the error back to each layer and calculates partial derivatives with the chain rule, so it finds the direction of improvement |
| Gradient descent | Uses those derivatives to adjust the weights and biases for the next round of feed forward, so it makes the change |

## Testing and inference

When training ends, the network is tested on new unseen data and its performance is measured. This is usually called inference. The weights are not trained on the test data. Textbooks add that this shows how well the function works beyond the training samples.
