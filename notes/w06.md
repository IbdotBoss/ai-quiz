# Neural networks and how they learn

## The perceptron
A **perceptron** is the simplest neural network, a single neuron with several inputs and one output. It is loosely modelled on a brain cell, with inputs in place of dendrites and an output in place of the axon. Each input is multiplied by a **weight**, which sets how strongly that input counts. The products are added up and a **bias** is added, which shifts the total whatever the inputs are. The **activation function** then checks the weighted sum and decides whether the neuron's output connections fire. A step function gives 0 or 1, and sigmoid and softmax are other common choices.

A single perceptron can only learn **linearly separable** patterns, where one straight line splits the classes. It cannot learn XOR however long it trains. A network joins many perceptrons in layers, an input layer, one or more **hidden layers** and an output layer. Each layer turns its inputs into features, and together the layers turn the inputs into a prediction.

> The weight scales one input, the bias is added once, and the activation function makes the decision.

## Why the activation function matters
The activation function adds **nonlinearity**. Without it, or with only linear activations, a stack of layers collapses into one linear function, so the extra layers add no power to model curved patterns.

## How a network learns
Learning is supervised. The right output for each training example is known, as with the iris dataset, where four flower measurements are the features and the flower type is the label. Training runs as a loop.

1. **Initialise** every weight and bias with random values, so the first predictions are random.
2. **Feed forward** from the input layer to the output layer to make a prediction.
3. Apply the **cost function** to measure the error between the prediction and the true label.
4. **Backpropagate** the error to each layer to find each weight's share of it.
5. Use **gradient descent** to adjust the weights and biases to reduce the error.

The loop repeats over many **epochs** until the cost converges or a maximum number of epochs is reached. The trained network is then tested on unseen data, called **inference**.

**Weights and biases** are the **trainable parameters**. The data and the architecture stay fixed during training.

> Loss is the error for one example. Cost is the average loss over the training set.

## Cost functions
A cost function turns the error into one number that training tries to make as small as possible. **Mean squared error** suits regression, such as house prices, and gives far predictions a large penalty. **Binary cross entropy** suits classification with targets of 0 or 1, such as spam or not spam.

## Gradient descent
**Gradient descent** uses the slope of the cost with respect to each weight to decide which way to move it. A positive slope means the cost rises as the weight rises, so the weight is lowered. Repeating this lowers the cost step by step.

> Backpropagation finds the gradients. Gradient descent uses them to change the weights.
