# Neural network basics, perceptron and training

## The brain and the artificial neuron
A biological neuron receives impulses through its dendrites and passes them along its axon to other neurons. Artificial neurons copy this idea at a small scale. Inputs play the part of dendrites and the output plays the part of the axon.

## The perceptron
A perceptron is a single neuron with several inputs and one output. Each input is multiplied by a weight and the products are summed. A bias is added, and an activation function decides whether the neuron fires. A step function gives one of two values. Weights and biases start random and are adjusted later.

## Limit of one perceptron and layered networks
A single perceptron only learns linearly separable patterns. Thousands of perceptrons in consecutive layers turn the input data into predictions based on features.

## Supervised learning
Neural networks generally learn with labelled data. The desired output for each sample is known, as with the iris features and the flower type label. The aim is to learn a function that links inputs to labels.

## The training loop
Training is iterative. Start with random weights and biases, so the first prediction is meaningless. Then repeat these steps.

- Feed forward from input to output to make a prediction.
- Use the cost function to measure the error.
- Backpropagate the error to each layer.
- Use gradient descent to adjust weights and biases.

Each full round of these steps is one epoch. Stop when the cost converges or the maximum number of epochs is reached.

## Cost and loss
Loss usually means the error for one observation. Cost is the average loss over the training set. Both turn the prediction error into one real number.

| Task | Cost function |
|---|---|
| Regression | Mean squared error, mean absolute error |
| Classification with targets of 0 or 1 | Binary cross entropy |

Mean squared error punishes far predictions much more than close ones.

## Gradient descent and backpropagation
The slope of the cost shows which way to move. The weights move in the negative direction of the slope. Backpropagation calculates the partial derivatives with the chain rule. Gradient descent uses them to make the update.

## Testing
After training, the network is tested on new unseen data and its performance is measured. This is called inference.
