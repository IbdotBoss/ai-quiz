# Image Segmentation and Object Detection

## Classification versus segmentation
Classification gives one label to the whole image. Segmentation gives a class to every pixel. It shows where the object is and can find several objects. Its labels are binary mask images, which take a lot of effort to make.

## U-Net
U-Net rebuilds an image from a feature vector, and its shape looks like a U.
- Contraction blocks use convolution then max pooling.
- The bottleneck sits in the middle.
- Expansion blocks use convolution then up sampling.
- Copy and crop passes earlier feature maps across to make up for information lost in max pooling.

## Segmentation versus detection
| | Segmentation | Detection |
|---|---|---|
| Output | Pixel mask | Boxes with labels |
| Detail | Fine | Coarse |
| Speed | Slower | Faster |
| Example use | Medical imaging | Real time vehicle finding |
| Models | U-Net, SegNet | YOLO, SSD, Faster R-CNN |

## Detection labels
A detection label holds the box centre x and y, the width and height, and the class. A one hot vector alone cannot do this.

## YOLO
YOLO looks at the whole image in one forward pass.
1. Resize, normalise and divide into a grid.
2. A CNN backbone makes a feature map.
3. Each cell predicts several anchor boxes with confidence scores.
4. Classes are predicted. YOLOv3 uses sigmoid, so one object can have several classes.
5. Non maximum suppression removes duplicates.
6. The output is boxes, labels and confidence scores.

## Non maximum suppression
Keep the most confident box. Discard others that overlap it above the threshold using intersection over union. Repeat.
