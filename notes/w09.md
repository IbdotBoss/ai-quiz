# Image segmentation and object detection

## Classification versus segmentation
**What it is.** Classification gives one label to the whole image, such as cat or car. Segmentation gives a class to every pixel, so it shows where the target object is.

**Why segmentation exists.** Sometimes the target fills only a small part of the image and other objects share the frame. A photo of a person and a dog cannot be labelled correctly as just DOG or just HUMAN. We may also want to know whether there is a dog, where it is and how many there are. Segmentation can find several occurrences of the object across the image. It is used where each pixel needs a label, such as self-driving cars, cancer segmentation and brain tumour segmentation.

**Different labels.** A classifier is trained with one categorical or numerical label per image. A segmentation network is trained with a binary mask image, which marks the object pixels. It also outputs a prediction mask image rather than a single label. So the network must turn the image into a feature vector and then rebuild an image from it. Making ground-truth masks is labour intensive, which is a real cost of segmentation.

**Common mistake.** Treating the mask as an extra decoration. It is the label itself, and the network is trained against it.

## U-Net
**What it is.** U-Net is a segmentation network that converts the image into a feature vector and then reconstructs a segmented image from it. Its architecture looks like the letter U, which gives it the name.

**How it works.** It has three sections. Contraction blocks each use two 3 by 3 convolution layers followed by 2 by 2 max pooling, so the maps shrink and the features get compressed. The bottleneck mediates between the contraction layers and the expansion layers. Expansion blocks each use two 3 by 3 convolution layers followed by a 2 by 2 up-sampling layer, so the maps grow back towards the size of the original image.

**Why copy and crop.** Max pooling loses some information as it shrinks the maps. Each expansion block therefore receives a copy and crop of the feature map from the matching contraction block. This compensates for the lost information. Textbooks add that the copied maps give the expansion path fine spatial detail, which helps draw sharp object boundaries.

**Confused with.** Contraction shrinks with max pooling and expansion grows with up-sampling. Do not swap them. Also remember that copy and crop is the link across the U between matching blocks.

## Segmentation versus object detection
| | Segmentation | Object detection |
|---|---|---|
| Output | A pixel-level mask with the exact shape and boundary of each object | Bounding boxes, each with a class label |
| Detail | Fine | Coarser |
| Speed | Slower | Faster |
| Suits | Medical imaging and satellite image analysis | Real-time tasks such as pedestrian or vehicle detection |
| Models | U-Net and SegNet | Faster R-CNN, YOLO and SSD |

Choose segmentation when the exact outline matters, such as the boundary of a tumour. Choose detection when speed matters more than fine detail, such as finding vehicles in live video.

## Detection labels
In classification the label is a one hot vector. For four classes, person is 1 0 0 0 and bottle is 0 1 0 0. That vector says only which class the whole image belongs to. For detection the label must also hold what is needed to rebuild the bounding box. The model predicts at least five values, which are the centre x and y of the box, the width and height of the box, and the class label. In short, classification says what, and detection says what and where.

## YOLO
**What it is.** YOLO stands for You Only Look Once. It is a real-time object detection model that processes the entire image in one forward pass. That makes it extremely fast compared with older methods such as Faster R-CNN. Other popular detectors are the R-CNN family, SSD and DETR.

**Step 1, input processing.** The image is resized to a fixed shape, typically 416 by 416 or 608 by 608, so any image can be handled consistently. Pixel values are normalised from 0 to 255 to a scale of 0 to 1, which helps the network learn faster and stops large pixel values dominating. The image is then divided into an S by S grid. In YOLOv3 a 416 by 416 image gives a 13 by 13 grid.

**Why a grid.** Each cell is responsible for objects whose centre falls inside it. This is faster and more efficient than checking every possible region, as R-CNN does.

**Step 2, feature extraction.** A CNN backbone such as Darknet turns the image into a feature map, picking up edges, textures and shapes. Darknet-19 is used in YOLOv2 and Darknet-53 in YOLOv3.

**Step 3, bounding boxes.** Each cell predicts several boxes. Each box holds the centre x and y relative to the cell, the width and height relative to the whole image, and a confidence score from 0 to 1 that an object is present. Each cell uses anchor boxes, usually 3 to 5 per cell, because objects have different shapes. For example a cell holding a car and a person can use one anchor for each.

**Step 4, class prediction.** Each cell gives class probabilities only for objects it detects. Older YOLO versions used softmax, which assigns one class per object. YOLOv3 and later use sigmoid, which allows several classes for one object. This helps in multi-label classification. Softmax and sigmoid are easily mixed up, so remember that sigmoid is the newer one.

**Step 5, non-maximum suppression.** This removes duplicate boxes, as the next section explains.

**Step 6, final output.** A list of detected objects, each with box coordinates, a class label and a confidence score.

## Non-maximum suppression
Several boxes often overlap the same object, so redundant ones must go. First sort all boxes by confidence score and keep the highest. Then compare each remaining box with the kept one using intersection over union, which measures how much two boxes overlap. If the overlap is above a threshold such as 0.5, the box is a duplicate and is discarded. If it is below, the box is kept, because it probably covers a different object. Repeat for the remaining boxes.

**Common mistake.** Thinking that intersection over union picks the best box. Confidence picks the best box, and intersection over union only measures overlap.
