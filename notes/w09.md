# Segmentation and object detection

## Classification, detection and segmentation
**Image classification** gives one label to the whole image, such as cat. **Object detection** finds each object and gives it a class and a **bounding box**. **Image segmentation** gives a class to every pixel, so it shows the exact shape of each object. A photo of a person and a dog cannot be labelled as just DOG or HUMAN, which is why detection and segmentation exist.

Segmentation suits tasks where the exact outline matters, such as the boundary of a tumour in a scan. Detection gives a coarser but faster result, so it suits real-time tasks such as finding pedestrians and cars in video. A segmentation network is trained on **mask images** that mark the object pixels, and it outputs a predicted mask.

> Classification says what. Detection says what and where. Segmentation says exactly which pixels.

## U-Net
**U-Net** is a segmentation network shaped like the letter U. It turns the image into features and then rebuilds a segmented image.

- **Contraction blocks** each use two 3 x 3 convolution layers followed by 2 x 2 **max pooling**, so the maps shrink and features are extracted.
- The **bottleneck** links the contraction and expansion paths.
- **Expansion blocks** each use two 3 x 3 convolution layers followed by 2 x 2 **up-sampling**, so the maps grow back towards the image size.
- **Copy and crop** connections, also called skip connections, pass each contraction feature map to the matching expansion block. They restore the spatial detail lost during max pooling, which gives sharp boundaries.

The output is a segmentation mask.

> Contraction shrinks with max pooling. Expansion grows with up-sampling.

## YOLO
**YOLO**, You Only Look Once, is a real-time object detector that processes the whole image in one forward pass, which makes it much faster than older methods such as Faster R-CNN. The image is resized, for example to 416 x 416, normalised to the range 0 to 1, and divided into a grid, 13 x 13 in YOLOv3. A CNN backbone such as Darknet extracts features. Each grid cell is responsible for objects whose centre falls in it and predicts several **anchor boxes**, each with its centre, width, height and a **confidence score**. Each cell also predicts class probabilities.

**Non-maximum suppression** removes duplicate boxes. Sort boxes by confidence and keep the highest. Compare each other box with it using **intersection over union**, which measures overlap. Discard boxes that overlap above a threshold such as 0.5, since they are duplicates, and repeat.

> Confidence picks the best box. Intersection over union only measures overlap.
