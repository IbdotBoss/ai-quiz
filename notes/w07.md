# Forward pass, total error and weight updates in a small network

The perceptron, the loop outline, the cost functions and the idea of gradient descent are in the week 6 note.

## The example network

**What it is.** The worked example has two inputs, two perceptrons in a hidden middle layer and two perceptrons in the last layer. The hidden layer sits between the inputs and the last layer. The size is small so the working can be followed, and the same process scales to a network of any size.

**Starting point.** The example gives initial weights, biases, training inputs and targets. The weights are random, so nothing has been optimised and the first prediction is poor. Backpropagation aims to improve them so the next prediction has less error.

## The forward pass

**What it is.** The forward pass moves from the input layer towards the output layer and produces a prediction.

**How it works.** Each perceptron first finds its total net input, which is its weighted inputs plus its bias. It then applies the logistic activation function to that net input to get its output. The hidden perceptrons do this first. Their outputs become the inputs of the last layer, which repeats the same two steps. The outputs of the last layer are the prediction. Textbooks add that the logistic function squeezes any net input into a value between 0 and 1.

**Example.** In the course example the first output neuron predicts about 0.75 against a target of 0.01, and the second predicts about 0.77 against a target of 0.99. Both are well off, as random weights would give.

**A common mistake.** Saying the forward pass changes the weights or is where learning happens. It only uses the current weights to make a prediction.

## Total error

**What it is.** Each output neuron has a target and a prediction. The cost function combines the errors of the output neurons into one total error for the network.

**Why it is needed.** Training needs a single quantity to reduce, and the backward pass measures every weight against it. In the example the two output neurons each contribute to the total.

**Easily confused.** Loss is for one observation and cost is an average over the training set. Here the combining is across output neurons, and the course calls the result the total error.

**A common mistake.** Forming the total from only the first output neuron, or from the hidden neurons. Only the output neurons have targets.

## The backward pass

**What it is.** The backward pass starts from the error at the output and works back through the layers. Its goal is to update every weight so the predictions move closer to the targets, which lowers the error for each output neuron and for the network as a whole.

**How it works.** For one weight, the key question is how much a change in that weight would change the total error. The answer is the partial derivative of the total error with respect to the weight. Textbooks explain that partial means only that weight varies while all the others are held fixed. A larger value means the weight has more effect on the error.

**Easily confused.** The backward pass includes backpropagation, which finds the derivatives, and then gradient descent, which uses them to change the weights. Backpropagation does not change any weight itself.

## Why the chain rule

**What it is.** A weight does not touch the total error directly. It changes the total net input of its neuron. That changes the neuron's output, and that output changes the error. The chain rule multiplies the effect of each link, giving three pieces.

- How much the total error changes with the neuron's output.
- How much the output changes with the total net input.
- How much the total net input changes with the weight.

**Why it helps.** Each piece is simple alone, so one hard question becomes three easy ones.

**Zero terms.** A piece drops out as zero when the weight has no effect on it. For a weight into the first output neuron, the error of the second output neuron drops out, because that weight does not influence it.

**A common mistake.** Treating the learning rate as one of the pieces. The learning rate enters later, at the update.

## Weight update and learning rate

**What it is.** Gradient descent subtracts the gradient from the current weight, which moves the weight in the opposite direction to the gradient. The gradient points towards higher error, so going the other way lowers the error. The learning rate scales the step. The course example applies a learning rate of 0.5.

**Easily confused.** The learning rate is chosen by people before training, while training adjusts the weights. Textbooks make this point.

| Learning rate | Effect |
|---|---|
| Too large | Steps overshoot the minimum and the error bounces up and down |
| Too small | Each step is tiny, so learning is very slow |

Textbooks give these effects. A good value lies between the two and lets the error fall steadily.

**A common mistake.** Setting the rate to zero to stop the bouncing. The weights would then never change and learning would stop. To calm a bouncing error, reduce the rate.

## Updating every weight and bias

**What it is.** The same process updates every weight and bias in every layer and perceptron.

**Why backpropagation is needed.** The cost function measures the error only at the output, yet the weights and biases of every layer influence that error. Backpropagation sends the error back systematically so each parameter can be corrected. Without it the earlier layers could not be trained.

**A common mistake.** Believing only the output layer is updated.

## The next round and the end of training

After the update, a new forward pass runs with the new weights. The course counts this as the next epoch, whereas textbooks define an epoch as one pass over the whole training set. The cycle repeats until the cost converges or the maximum number of epochs is reached. The finished network is then tested on unseen data, which is called inference.

## Forward pass and backward pass compared

| | Forward pass | Backward pass |
|---|---|---|
| Direction | Inputs to outputs | From the error back through the layers |
| Job | Makes a prediction with the current weights | Works out how each weight affects the error, so the weights can be updated |
| Changes the weights | No | It leads to the update that does |

Both run in every round of training.
