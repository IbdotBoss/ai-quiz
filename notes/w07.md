# Feed forward and backpropagation in a multi-layer network

## Size of the example network
The worked example has two inputs, two perceptrons in a hidden middle layer and two perceptrons in the last layer. The same process scales to a network of any size.

## Forward pass
The forward pass moves from the input layer towards the output layer. Each perceptron finds its total net input and then applies the logistic activation function to get its output. The last layer gives the prediction. With random starting weights the first prediction is poor.

## Total error
Each output neuron has a target and a prediction. The cost function combines these errors into one total error for the network. This is the quantity training tries to reduce.

## Backward pass
The goal is to update every weight so the predictions move closer to the targets. The key question is how much a change in one weight changes the total error. That answer is a partial derivative.

## Why the chain rule
A weight reaches the error only through a chain of effects. It changes the net input, which changes the output, which changes the error. The chain rule multiplies the pieces together. A term drops to zero when the weight has no effect on that term, such as the error of the other output neuron.

## Weight update and learning rate
Gradient descent moves each weight opposite to its gradient, so the error falls. The learning rate scales the step.

| Learning rate | Effect |
|---|---|
| Too large | Steps overshoot the minimum and the error bounces |
| Too small | Learning is very slow |

## Updating every weight and bias
The same process updates every weight and bias in every layer. Backpropagation matters because the error is measured at the output but every layer affects it. It sends the error back so each layer can be adjusted.

## Forward and backward compared
The forward pass goes from inputs to outputs and makes a prediction. The backward pass goes from the error back through the layers and finds how to change the weights. After the update, a new forward pass starts the next epoch.
